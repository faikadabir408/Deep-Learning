# Deep Learning Practical Experiments

This repository contains practical experiments and implementations of deep learning algorithms and neural network architectures built using Python, TensorFlow, PyTorch, and Keras.

##  Experiments Included

- Foundations of Neural Networks, Activation Functions & Backpropagation
- **Deep Neural Networks (DNN):** Multi-layer perceptrons for classification tasks
- **Autoencoders:** Unsupervised feature extraction and reconstruction
- **Deep Learning Models:** Custom model architectures and training pipelines
